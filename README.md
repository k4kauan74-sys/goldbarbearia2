# Gold Barbearia - High-End Grooming

Este é um sistema premium de barbearia desenvolvido com Next.js, Tailwind CSS e Firebase (Firestore & Auth). O projeto oferece uma experiência exclusiva para clientes e uma gestão simplificada para a equipe.

## 🚀 Funcionalidades

### 📅 Agendamento em Tempo Real
- Fluxo de agendamento intuitivo (Serviço > Profissional > Data > Horário).
- Validação de disponibilidade: horários ocupados são bloqueados automaticamente.
- Sincronização instantânea com o banco de dados Cloud.

### 👑 Clube de Assinaturas (MVP)
- Exibição de planos (Básico e Gold) com foco em assinaturas semestrais.
- Integração de links de checkout direto para InfinitePay.
- Painel do assinante para visualização de status e benefícios.

### 🔐 Painel Administrativo (Staff)
- Dashboard com métricas de geração e agenda do dia.
- Notificações via Toast em tempo real para novos agendamentos.
- Gestão de Profissionais: controle de expediente (working hours) e especialidades.
- Gestão de Serviços: cadastro e edição de preços, durações e descrições.
- Login seguro para administradores e barbeiros (Staff).

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Estilização:** Tailwind CSS & Shadcn UI
- **Backend/DB:** Firebase Firestore
- **Autenticação:** Firebase Auth (Anon & Password)
- **Ícones:** Lucide React
- **Pagamentos:** InfinitePay (External Links)
