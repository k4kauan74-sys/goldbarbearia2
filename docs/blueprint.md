# **App Name**: GoldBarbearia

## Core Features:

- Homepage & Service Display: A responsive homepage featuring 'Agende seu corte' title, a prominent 'Agendar' button, and clear sections to showcase services with pricing (Corte, Barba, Corte + Barba, Other) and professional profiles.
- Appointment Scheduling Interface: An intuitive, multi-step booking form allowing clients to select desired service, choose a professional, pick an available date from a calendar, and select a time slot. Includes client contact details input, form validation, and a confirmation message upon successful booking.
- Secure Admin Authentication: A secure login system with username and password for administrative users to access the management panel, ensuring only authorized personnel can make changes.
- Admin Appointment Management: A dedicated dashboard for administrators to view, filter, update (e.g., status, professional), block, or delete scheduled appointments. Displays comprehensive details for each booking.
- Admin Data Configuration: Tools within the admin panel for managing the barber shop's operational data: adding/editing professional details (photo, name, specialty, active status), updating service names and prices, and setting/blocking professional availability schedules.
- Relational Database System: Backend database integration using MySQL or SQLite to store and manage all application data including client appointments, professional details, service offerings, administrator credentials, and available time slots.

## Style Guidelines:

- Primary brand color: A rich, warm gold (#D9AE1A) to signify premium service and elegance. It stands out prominently on dark backgrounds.
- Background color: A deep, desaturated brownish-gray (#2F2C24), providing a sophisticated and elegant canvas that enhances the golden accents.
- Accent color: A warm, muted copper-orange (#B3471A) for interactive elements, highlights, and subtle calls to action, providing contrast and complementing the primary gold.
- Headline font: 'Playfair', a modern serif font chosen for its elegant and high-end feel, aligning with the premium aesthetic.
- Body text font: 'PT Sans', a humanist sans-serif, selected for its modern look, excellent readability, and a touch of warmth that balances the elegant headlines.
- Minimalist, clean line icons related to barber services (e.g., scissors, razor, comb) and scheduling (e.g., calendar, clock) to maintain a modern and uncluttered visual style.
- A responsive, mobile-first design with clean and organized content blocks. The layout prioritizes clear visual hierarchy and easy navigation to enhance user experience on all devices.
- Subtle and smooth transition animations for form steps, button hovers, and section changes, providing a polished and engaging user experience without distraction.
